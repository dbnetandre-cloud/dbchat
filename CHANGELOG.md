# Histórico de versões

Cada versão está marcada com uma tag do Git. Para ver ou voltar a uma versão antiga:

```
git checkout v1.0      # ver a versão 1.0
git checkout main      # voltar para a mais recente
git diff v1.0 v1.1     # ver o que mudou entre as duas
```

## v1.3 — 2026-10-07

## v1.0 — 2026-10-06
Primeira publicação.
- Chat do Opa Suite com visual próprio: cabeçalho DBNET, avatares, nome fora do balão e fundo com o logo.
